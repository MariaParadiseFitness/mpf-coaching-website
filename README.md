# MPF Coaching website

Maria Paradise's official website for MPF Online Coaching (mpfcoaching.co.uk).

## What's in here
- `index.html` – main page ("Want to work with me?")
- `hypertrophy.html` – interactive Hypertrophy Guide
- `diet.html` – interactive Flexible Dieting Guide with calorie & macro calculator
- `img/` – photos, transformations and logo
- `fonts/` – brand fonts used by the guides
- `guides/` – PDF versions of the guides

## Updating the site
Edit the files, commit and push to GitHub. If the repo is connected to Netlify, the live site updates automatically.
